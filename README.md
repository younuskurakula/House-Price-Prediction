# 🏠 Advanced House Price Prediction

A machine learning regression project based on the **Kaggle House Prices: Advanced Regression Techniques** competition. The goal is to predict residential house sale prices using property features such as location, quality, area, rooms, and other attributes.

## 🎯 Objective

Build an end-to-end ML pipeline to predict **`SalePrice`** and understand the key factors influencing house prices.

## 📊 Dataset

* **Source:** Kaggle — House Prices: Advanced Regression Techniques
* **Target:** `SalePrice`
* **Files:** `train.csv`, `test.csv`
* **Problem Type:** Supervised Learning → Regression

## 🔧 Workflow

1. Exploratory Data Analysis (EDA)
2. Missing Value Treatment
3. Feature Engineering
4. Categorical Encoding
5. Feature Selection
6. Train/Validation Split
7. Model Training
8. Cross-Validation
9. Hyperparameter Optimization
10. Model Evaluation & Prediction

## 🤖 Model

**Gradient Boosting Regressor**

* Handles nonlinear relationships effectively
* Works well with engineered numerical features
* Evaluated using **rootmeansquareerror rmse Score** and regression metrics

## 📈 Result

**IN Local System rmse Score: 0.11436**
**IN Kaggle Competion rmse Score: 0.12771**

The model demonstrates strong predictive performance while providing a practical end-to-end example of a regression workflow.
